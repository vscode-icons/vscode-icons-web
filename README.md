## Overview

VSCode Icons Web is a browser extension that replaces file and folder icons on
supported code hosting sites with icons from
[vscode-icons](https://github.com/vscode-icons/vscode-icons). It uses the
[VSCode Icons API](https://github.com/vscode-icons/vscode-icons-api) to resolve
icons.

## Supported browsers

- Google Chrome
- Microsoft Edge
- Mozilla Firefox

## Supported sites

- GitHub repositories and GitHub Gists
- GitLab
- Codeberg
- Bitbucket
- SourceForge
